# Salary and Job Offer Planner

## What it does

It takes two monthly job-offer salary breakdowns and budget details and gives estimated take-home pay, savings capacity, and a comparison in Saudi riyals (SAR).

## Who it is for

Anyone comparing a monthly job offer or planning a simple monthly budget. It is an estimate, not payroll, tax, or legal advice.

## Needs

Nothing but a browser. The app has no packages, server, database, API, environment variables, or external dependencies.

## How to run it

Start from a fresh download of this repository and extract it.

### Windows

Open Command Prompt in the extracted project folder.

```text
start index.html
```

### Mac

Open Terminal in the extracted project folder.

```text
open index.html
```

The planner opens in your default browser. It also works by double-clicking `index.html`.

## Try it with the sample data

The page starts with fictional built-in sample values from `sample-data/data.js`. Click **Load example** to restore them at any time. You should see an estimated Offer A take-home of **8,596.88 SAR**, **5,596.88 SAR** left after the example bills, a four-month timeline for the example savings goal, and Offer B estimated as **564.06 SAR** more per month.
